HTML Tools

Single-file tools — no build step, no frameworks. Inspired by Simon Willison's HTML tools.

JSON to Table
Paste a JSON array and get a clean, minimal table. Handles nested objects with dot-notation column headers.
Sleep Calculator
Calculate optimal sleep and wake times based on 90-minute sleep cycles.
JWT Decoder
Decode, encode, edit, and verify JWTs with inline editing, timestamp pickers, re-signing, and history.
Retirement Calculator
Project your retirement savings growth and see if you're on track with an interactive chart.
Interval Timer
Full-screen workout timer for EMOM, Tabata, AMRAP, and HIIT. Background color changes with each interval for easy at-a-glance visibility.
Username Generator
Generate random usernames from adjectives, colors, and animals. Supports multiple casing styles and optional number suffix.
Measurement Sense
Build intuition for metric units through vivid real-world anchors and a slider-based quiz with spaced repetition. No math required.
Party Host
Manage turn order and scoring for party games. Randomly picks who goes first, then rotates. Tap +1/−1 to keep score.
