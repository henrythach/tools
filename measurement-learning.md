# Measurement Sense

Build intuition for metric units — no math required.

Two modes:

- **Browse** — scan vivid, context-tagged anchor examples across six categories (temperature, weight, speed, distance, height, volume). Each card shows the metric value prominently, its imperial equivalent, a context tag (Weather, Cooking, Body, etc.), and a concrete description to make it stick.

- **Quiz** — see a metric value, drag a slider to your best imperial guess, then reveal the answer. A streak counter tracks consecutive correct guesses. A lightweight spaced repetition system weights missed anchors more heavily so you see them again sooner.

Primary audience: Americans building intuition for metric. No formulas or math — just memorable context clues.
